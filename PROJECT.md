# MalaForge · MalaCall

The **MalaForge** panel + **MalaCall** analysis pipeline: a single low-cost amplicon assay to detect,
speciate, and profile **all five human-infecting
Plasmodium species** — *P. falciparum, P. vivax, P. ovale* (curtisi + wallikeri), *P. malariae*,
and *P. knowlesi* — in one workflow.

Builds on the validated low-cost-mal-seq design (tailed-amplicon backbone, custom barcodes,
platform-agnostic ONT/Illumina/MGI) and extends it to a truly pan-Plasmodium panel:

- **Species detection & identification** (all 5, incl. Po curtisi/wallikeri) from conserved-priming /
  species-discriminating targets, using degenerate primers on conserved flanks.
- **Drug-resistance profiling** across species orthologs (dhfr, dhps, crt, mdr1, k13, cytb, …).
- **Diagnostic-resistance** (pfhrp2/3 deletions; pan-pLDH context).
- **Parasite diversity** (per-species microhaplotypes).

Target: the 8 cross-cutting criteria (US $1–10/sample; simplicity; LMIC robustness; modularity;
scalability; data quality; cold-chain independence; platform-agnostic).

Status: reference assembly + target definition + primer/probe design with rigorous in-silico validation.
