Basis. Figures are reagent + consumable costs at manufacturer list prices, matching the original US $1–10/sample target — they exclude labor, instrument capital/amortization, shipping, and overhead. Two structural savings keep the floor low and are already built into the assay: no extraction kit (5-minute lysis, −$2–5) and no library-prep kit (the two-step tailed-amplicon PCR replaces it, −$25–65).

How seq $/sample is computed. capacity = min(9,216 barcodes, reads_per_run ÷ reads_per_sample); runs = ⌈batch ÷ capacity⌉; seq $/sample = runs × flow-cell $ ÷ batch. Under-filling a run raises the per-sample cost (you still pay for the whole flow cell); filling it drives it toward flow-cell $ ÷ capacity.

Platform notes. ≤400 bp amplicons merge on Illumina 2×250 and run native on ONT/MGI; the median amplicon is 240 bp, so most also merge on cheaper 2×150. ONT throughput assumes R10.4.1. The 289-amplicon count is ~18% more reads than the pre-re-tile design, but the re-tile unlocked Illumina/MGI (previously ONT-only), whose per-read cost is far lower — net effect on cost is neutral-to-favourable. Prices vary by region, contract, and year; treat as order-of-magnitude.

Turnaround (TAT). Sample-to-answer = prep (~5 h, constant) + sequencing + analysis. Prep is one working session (5-min lysis → round-1 multiplex PCR → clean-up → round-2 barcoding PCR → pool/QC). ONT streams data in real time, so a MinION/Flongle gives a same-day answer (~8–14 h) — the platform of choice for clinical or outbreak turnaround. Illumina/MGI are batch instruments: the run itself is 15–56 h, so total TAT is ~1.5–3 days. This is the trade-off against cost: ONT is fastest; MGI/NovaSeq are cheapest but slowest and need large batches. TAT is per-run and independent of batch size; analysis assumes the standard Nextflow pipeline on a modest server.
